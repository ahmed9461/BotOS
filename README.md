# BotOS

**بوتاتك، بطريقتك.** تطبيق Android يجمع بوتات Telegram المحفوظة في مساحة واحدة. تضيف اسم البوت وتسميه وتتفاعل مع رسائله وأزراره، دون توكنات بوتات أو تعديل كل بوت.

## واجهة المراسلة — سلسلة0.6

المهمة0008 في `feat/messenger-ui-v3` / PR7 تعيد تصميم التطبيق الفعلي: قائمة بوتات وبحث، محادثات ووسائط متناسبة وعارض كامل الشاشة، مرفقات وتسجيل صوت، صور دائرية وألوان فاتحة وداكنة ورموز أصلية. لا وجهة أو رسائل أمثلة في التطبيق؛ المحتوى الاصطناعي محصور في test وandroidTest. تأكيد المرفق الذي اختاره المستخدم ليس شاشة أمثلة.

حالة البناء والتسليم الحالية وبصمة النسخة الموقعة في [ذاكرة المشروع](docs/PROJECT_MEMORY.md) و[الاختبارات](docs/TESTING.md)، لا يُستنتج جاهزيتها من رقم الإصدار وحده. PR يبقى غير مدمج حتى قبول المالك. نجاح المحاكي ليس تجربة الهاتف أو حساب Telegram الحقيقي.

## التحديث وهوية التثبيت

هوية تسليم المالك `com.ahmed9461.botos.app` باسم **BotOS**، والشهادة الدائمة نفسها منذ0.4. تحديث0.6 يستهدف النسخة0.5 بهذه الهوية دون إزالة التطبيق أو بياناته. تحقق البوابة ترقية0.5→0.6 على محاكي بشهادة CI المؤقتة، والتوقيع النهائي للمالك يتم بصورة مستقلة بالمفتاح الدائم؛ لا يخلط الدليلان.

نسخة0.3 الأقدم ذات الهوية `com.ahmed9461.botos.preview` تطبيق منفصل؛ لا تُحذف ولا تُنقل جلستها تلقائيًا. المفتاح الدائم وملف الاستعادة محفوظان في Library الخاصة بالمالك؛ الشهادات العامة فقط في `delivery/`. لا تنشئ شهادة بديلة عند فقد ملفات بيئة العمل المؤقتة. [إجراءات التسليم والاستعادة](docs/OWNER_DELIVERY.md).

## القدرات والحدود

الربط يتحقق من هوية البوت، ويعرض النصوص والتاريخ المحدود والتعديلات والحذف، ويدعم Inline callback وروابط بتأكيد ولوحة Reply النصية. Rich يشمل عناوين ونصوصًا منسقة وقوائم وجداول واقتباسات وتفاصيل وأزرارًا، مع معالجة المحتوى الجزئي وعزل الأفعال القديمة.

الصور ووسائط محلية مدعومة ومرفقات صادرة بتأكيد وتسجيل صوت وبث الردود متاحة بحسب [مصفوفة القدرات](docs/TELEGRAM_CAPABILITIES.md) و[تغطية Rich](docs/RICH_COVERAGE.md). **ليس دعمًا كاملًا لكل Telegram**: الرياضيات صيغة نصية، والرموز المخصصة لها بديل، وMiniApps والمدفوعات وأزرار الهاتف والموقع غير مكتملة. لا يدّعى دعم كل ترميز أو هاتف بناءً على المحاكي.

بناء PR بلا إعدادات Telegram لا يجمع بيانات دخول، ولا يُسلّم باعتباره النسخة المهيأة. إعدادات التطبيق تأتي من زوج مكتمل خارج Git؛ النسخة المهيأة تُسلّم مشفرة ثم توقع بمفتاح المالك، ولا تُنشر في مخرجات المستودع العامة.

## البناء

الإصدارات مثبتة في Gradle والقفل؛ راجع [BUILD](docs/BUILD.md) و[DEPENDENCIES](docs/DEPENDENCIES.md). لا ترقية عشوائية. CI يفحص JNI والتطبيق والجهاز والواجهة قبل تسليم خاص بالمالك. الأسرار لا تدخل PRCI أو Git.

```sh
python3 scripts/check_repo.py
python3 scripts/check_contrast.py
python3 scripts/check_ui_contract.py
python3 -m unittest discover -s scripts/tests -v
./gradlew :core:model:test :core:telegram:test :app:lintDebug :app:assembleDebug
```

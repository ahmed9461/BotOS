# BotOS

**بوتاتك، بطريقتك.** تطبيق Android يجمع بوتات Telegram المحفوظة في مساحة واحدة. تضيف اسم البوت وتسميه وتتفاعل مع رسائله وأزراره، دون توكنات بوتات أو تعديل كل بوت.

## الحالة — 0.5 موقّعة وجاهزة للمالك

استخدم المالك0.3 بحسابه وأكد عمل الربط الأساسي، ثم جرب0.4 وقيّمها. في فرع PR6 اجتازت صور البوتات والبث النصي والغني وعرض الوسائط واختيار المرفقات وتسجيل الصوت بوابات CI حتى CI90 بموارد اختبار مصطنعة. اجتاز 0.5.0-preview بناء المالك المهيأ واختبار الترقية على محاكي بشهادة CI، ثم وُقّع بالشهادة الدائمة المطابقة للنسخة المثبتة؛ APK النهائي ودليل بصمته خارج Git. تثبيته على هاتف المالك لم يُرصد بعد. حالة البناء والتسليم الفعلية في [ذاكرة المشروع](docs/PROJECT_MEMORY.md) و[الاختبارات](docs/TESTING.md).

## تثبيت بجانب النسخة السابقة

بموافقة المالك، هوية التسليم الجديدة `com.ahmed9461.botos.app` باسم **BotOS**. ليست تحديثًا لهوية0.3 `com.ahmed9461.botos.preview` ولا تحذفها أو تنقل جلستها. يسجل المستخدم الدخول ويضيف أسماء البوتات في التطبيق الجديد.

المفتاح الجديد ثابت، وحُفظت نسخته المشفرة فيLibraryالخاصة بالمالك مع ملف استعادة منفصل، وسُلّمت روابط الملفين بالفعل. الشهادات العامة فقط في`delivery/`. لا تنشئ مفتاحًا جديدًا عند فقد ملفات بيئة العمل المؤقتة. [إجراءات التسليم والاستعادة](docs/OWNER_DELIVERY.md).

## القدرات والحدود

الربط يتحقق من هوية البوت، ويعرض النصوص والتاريخ المحدود والتعديلات والحذف، ويدعم Inline callback وروابط بتأكيد ولوحةReplyالنصية. Richيشمل عناوين ونصوصًا منسقة وقوائم وجداول واقتباسات وتفاصيل وأزرارًا، مع معالجة المحتوى الجزئي وعزل الأفعال القديمة.

**ليس دعمًا كاملًا لكل Telegram.** فرع0.5 يعرض صورًا ووسائط محلية مدعومة ويجهز مرفقات صادرة بتأكيد، لكن نجاح المحاكي لا يثبت كل ترميز أو هاتف أو إرسال حساب المالك. الرياضيات صيغة نصية والرموز المخصصة لها بديل؛ MiniApps والمدفوعات وأزرار الهاتف والموقع غير مكتملة. [مصفوفة القدرات](docs/TELEGRAM_CAPABILITIES.md) و[تغطية Rich](docs/RICH_COVERAGE.md).

المعاينة المحلية منفصلة. بناءPRبلا إعداداتTelegram لا يجمع بيانات دخول، ولا يُسلّم باعتباره النسخة المهيأة.

## البناء

الإصدارات مثبتة فيGradleوالقفل؛ راجع[BUILD](docs/BUILD.md) و[DEPENDENCIES](docs/DEPENDENCIES.md). لا ترقية عشوائية. CIيفحصJNIوالتطبيق والجهاز والواجهة قبل تسليم خاص بالمالك. الأسرار لا تدخلPRCIأوGit.

```sh
python3 scripts/check_repo.py
python3 scripts/check_contrast.py
python3 scripts/check_ui_contract.py
python3 -m unittest discover -s scripts/tests -v
./gradlew :core:model:test :core:telegram:test :app:lintDebug :app:assembleDebug
```

# BotOS

مساحة واحدة لبوتاتك، بتجربة عربية هادئة وسلسة.

## حالة المستودع

2026-09-18: تم التحقق عبر GitHub من أن المستودع فارغ وتهيئته بهذا الملف. العمل الحالي هو تأسيس الذاكرة والتخطيط، ثم بناء أول شريحة Android قابلة للاختبار. لم يُنفّذ تسجيل الدخول إلى Telegram أو يُنتج APK في هذه اللحظة؛ تتغير الحالة فقط بدليل اختبار.

## ابدأ من هنا

قبل أي تعديل، اقرأ `AGENTS.md` ثم `docs/PROJECT_MEMORY.md` و`docs/ARCHITECTURE.md` و`docs/ROADMAP.md`، ثم خطة المهمة النشطة داخل `docs/tasks/`. هذه الملفات ستُضاف في خطوة التأسيس التالية.

## المنتج

تطبيق Android مخصص لاستخدام بوتات Telegram من حساب المستخدم، وليس منصة لتشغيل خوادم البوتات. يضيف المستخدم البوت باسم المستخدم، ويسمي تبويبه، ويعرض التطبيق المحتوى والأزرار التي يفهم أنواعها دون واجهة مخصصة لكل بوت. دعم نوع بروتوكول جديد قد يحتاج تحديث التطبيق؛ لا توجد وعود بدعم تلقائي لكل ميزة مستقبلية.

التكامل المستهدف هو TDLib، دون توكنات البوتات، مع توضيح طبيعة الاتصال بـ Telegram وحماية الجلسة. النسخة الأولى تبدأ بأساس الواجهة والمحرك واختباراته، ويُفصل وضع المعاينة صراحةً عن الاتصال الحقيقي.

# BotOS

**بوتاتك، بطريقتك.** تطبيق Android يجمع بوتات Telegram في مساحة يسمي المستخدم تبويباتها ويرتبها.

## الحالة الحالية

الجولة الثانية `0.2.0-preview` في مرحلة التحقق داخل طلب الدمج رقم 2، فوق فرع الأساس في طلب الدمج رقم 1. تتضمن إصلاح فراغ لوحة المفاتيح وتحديث إعدادات المظهر، وإعادة تصميم الألوان والواجهات، مع الإبقاء على أيقونة التطبيق المعتمدة.

**هذه معاينة محلية فقط.** لا تسجيل دخول Telegram أو اتصال TDLib أو إرسال حقيقي. الأسماء المحفوظة ليست بوتات متحققًا منها بعد. لا رموز دخول أو توكنات مطلوبة لتجربة المعاينة.

## الواجهة

ثيم الفاتح والداكن والنظام، تقليل الحركة، العربية والإنجليزية، تبويبات قابلة للتسمية والترتيب، مكتبة محلية قابلة للبحث، ومعاينة نصوص وجداول وأزرار وتفاصيل قابلة للطي. ملفات الأيقونة ومفاتيح التخزين محفوظة من الإصدار الأول.

## البناء والأدلة

JDK 21 وGradle 9.6.1 ومنصة Android 37، واسم حزمة المنصة `platforms;android-37.0`. راجع [دليل البناء](docs/BUILD.md) و[سجل الاختبارات](docs/TESTING.md). يولّد CI ملفات Gradle Wrapper الرسمية، ثم يبني التطبيق ويختبره.

```sh
python3 scripts/check_repo.py
python3 scripts/check_contrast.py
python3 scripts/check_ui_contract.py
./gradlew :core:model:test :core:telegram:test :app:lintDebug :app:assembleDebug
```

تضيف الجولة الثانية اختبارات جهاز على محاكي API 35 ولقطات شاشة وقياسًا للفراغ أعلى الكيبورد. وجود الاختبار أو workflow لا يعني أنه نجح؛ نتيجة كل تشغيل موثقة بعد قراءتها. توقيع المعاينة debug وليس مفتاح إنتاج المالك.

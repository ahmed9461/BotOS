# BotOS

**بوتاتك، بطريقتك.** مساحة Android عربية لبوتات Telegram، بهوية لؤلؤية/فحمية ولمسات موف، وتبويبات يختار المستخدم أسماءها.

## الحالة الحالية

بدأ تنفيذ **0.1.0-preview**: شريحة محلية لتجربة الواجهة وتنظيم البوتات ومحرك الرسائل. **لا تسجيل دخول Telegram ولا إرسال حقيقي ولا TDLib JNI في هذه النسخة بعد.** الأسماء المحفوظة bookmarks غير متحقق من كونها بوتات حتى تنفيذ الاتصال. شاشة المعاينة توضح أنها غير متصلة، ولا تطلب أي رمز دخول.

الكود يحتوي على ثيم النظام/الفاتح/الداكن، تقليل الحركة، واجهتي المساحة والمظهر، إضافة/تعديل/ترتيب/إزالة التبويبات مع حفظ محلي، فتح رابط البوت في Telegram، وعرض نماذج نص/جدول/اقتباس/قائمة/تفاصيل قابلة للطي وأزرار تغير الرسالة نفسها. هذا أساس renderer داخلي، لا ادعاء بدعم Telegram Rich Messages كاملًا.

## البناء والتحقق

JDK21، Gradle9.6.1، Android SDK37. [تعليمات البناء](docs/BUILD.md) تشرح توليد Wrapper الرسمي. لا توكنات أو مفاتيح لازمة للمعاينة.

```sh
python3 scripts/check_repo.py
python3 scripts/check_contrast.py
gradle --no-daemon :core:model:test :core:telegram:test :app:lintDebug :app:assembleDebug
```

[GitHub Actions](https://github.com/ahmed9461/BotOS/actions) يبني APK المعاينة ويرفعه مع تقارير وchecksum عند النجاح. وجود workflow لا يعني أنه نجح؛ راجع دليل الاختبارات للحالة الفعلية. الاختبارات المحلية: 37 assertion للنواة و14 زوج تباين نجحت. بناء Android وقت هذا commit بانتظار CI.

## ما بعد المعاينة

P2 يضيف TDLib مثبتًا على commit ومبنيًا مع JNI، حماية جلسة وحذفها عند الخروج، دخول حقيقي بإذن المستخدم، والتحقق من البوت ثم النصوص وأزرار Telegram وتحديثاتها. P3 يوسع rich/media/drafts بحسب المخطط المثبت واختبارات فعلية. لا AI لتخمين الأزرار، لا توكنات بوتات، ولا خادم يحتفظ بجلسة المستخدم.

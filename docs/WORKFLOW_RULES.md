# سير العمل

المصدر الملزم هو [AGENTS.md](../AGENTS.md). هذا الملف يحدد الأدلة العملية دون نسخ التعليمات في أماكن متعارضة.

## دورة المهمة

`planned → in_progress → validating → completed`، أو `blocked` مع سبب وخطوة حل. لا تغيير إلى completed اعتمادًا على وجود الكود فقط.

قبل تعديل التطبيق يجب أن توجد خطة في `docs/tasks/` ويشير إليها `PROJECT_MEMORY.md`. تكتب الخطة قبل التنفيذ، وتحدث قائمة التقدم أثناءه. عند الاستئناف تقرأ أحدث نسخة من الذاكرة والكود، ولا تعيد أعمالًا مكتملة اعتمادًا على ملخص قديم.

## سجل التنفيذ

يسجل لكل شريحة: تاريخها، branch/base، المتطلبات، الملفات، أوامر التحقق، النتائج، ما لم يمكن اختباره وسبب ذلك، القرارات، التراجع، الخطوة التالية. كل تغيير معماري يحتاج ADR موجزًا في `DECISIONS.md`.

## Git وCI

فرع عمل محدود لكل شريحة، commits ذات معنى، PR يربط بالخطة. الحفاظ على تغييرات المستخدم. لا أسرار ولا builds ولا caches في Git. متوقع إضافة فحص توثيق يمنع تغيير كود دون الذاكرة والسجل وخطة المهمة، وفحص بناء واختبارات. الفحص الآلي يستطيع التحقق من تغير الملفات لا من جودة الفهم؛ تبقى مراجعة الخطة والاختبارات واجبة.

## Definition of Done

المطلوب مستوفى أو حدوده موثقة صراحة، الاختبارات المناسبة نجحت بدليل، واجهة بلا نجاح وهمي أو أخطاء خام، الموانع معروفة، الوثائق متزامنة، وموضع الاستئناف دقيق. لا تخفِ اختبارًا فاشلًا أو تعطل فحصًا لتحصل على علامة خضراء.

# ADR-006 — تعديلات الواجهة بعد اختبار المالك

التاريخ: 2026-09-18. الحالة: معتمد للتنفيذ، والتحقق العملي جارٍ. يحدّث الاتجاه البصري في ADR-005، ولا يغير فكرة المنتج أو مرحلة الربط الحقيقي.

## السياق

المالك جرّب 0.1 وأبلغ عن مسافة زائدة فوق الكيبورد ومفتاح لا يعكس الحالة فورًا، ورفض الألوان الداخلية الثقيلة. أقر أيقونة التطبيق وطلب إبقاءها.

## القرار

يمتلك مستوى التطبيق وحده مساحات النظام والكيبورد، باتحادها لا جمعها، ولا تضيفها الشاشات الداخلية. يجمع محتوى كل وجهة حالته بنفسه؛ لا تمرير لقطة إعدادات قديمة إلى محتوى Navigation 3 المحتفظ به، ولا تغيير قسري لمفتاح الشاشة.

يعاد تصميم الداخل بألوان Porcelain / Graphite / Iris، وبطاقات أصغر ومعاينات ثيم واضحة، مع المحافظة التامة على الأيقونة والتخزين المحلي. تضاف اختبارات تشغيل حقيقية ولقطات وقياس، وليس فحص التجميع وحده.

## البدائل المرفوضة

طرح قيمة ثابتة من ارتفاع الكيبورد يعالج جهازًا واحدًا فقط. إعادة إنشاء شاشة المظهر عند كل نقرة تخفي خطأ الحالة وقد تفقد التمرير. تغيير كل المكتبات إلى إصدارات أحدث لا يعالج سبب المشكلة. أيقونة جديدة تخالف موافقة المالك الصريحة على الحالية.

## التحقق والحدود

قياس حقل الإدخال مع IME حقيقي، وتبديل متكرر داخل الشاشة والحفظ عبر إعادة الإنشاء، وصور من محاكي. جهاز المالك ولوحة مفاتيحه ومراجعة ذوقه البصري تظل مطلوبة. لا ضمان أداء أو ملاءمة فنية من نجاح هذه الاختبارات.

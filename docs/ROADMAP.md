# خارطة BotOS — بوابات مترابطة

## P0 — مكتمل: الذاكرة والعقود

AGENTS والخطة والذاكرة والبنية والتصميم والأمان ومصفوفة القدرات والقرارات والإصدارات الموثقة. أُنشئت قبل كود التطبيق.

## P1 — أساس المعاينة مبني ومتحقق آليًا

خمس وحدات Compose، ثيمات وRTL وتنقل، تنظيم bookmarks وتفضيلات، نماذج وrenderer ومعاينة مستقلة. run35288442618 اجتاز Python13 وcontrast14 وJUnit4 وlint وassembleDebug. lint بلا أخطاء مع9 تحذيرات موثقة؛ APK debug قابل للتتبع فيTESTING. لا ادعاء أن الواجهة اختبرت على جهاز أو أن النسخة تتصل بـTelegram.

**قبل الانتقال للحساب الحي:** مراجعة المعاينة على جهاز/محاكي وتسجيل أدلة التنقل والثيمات والخط واللغة، تثبيت Wrapper المولد بعد مراجعته، وإكمال قواعد حماية/نقل البيانات والتحسينات ذات الصلة. لا قفز فوق هذه المهام لمجرد نجاح التجميع.

## P2 — لم يبدأ الاتصال الحقيقي

خطة مستقلة بعد قراءة الذاكرة والمخطط الحالي. TDLib مثبت على commit، JNI ومخطط مطابقان، بيانات التطبيق خارجGit، login فعلي وحماية الجلسة ومحوها عندالخروج، تحقق userTypeBot، بدء صريح دون تكرار/start عندكلتبويب، ونصوص/Inline/Reply/edits/reconnect مع اختبارات حساب بموافقة المستخدم. لا توكنات بوتات ولا تغييرwebhooks.

## P3 — المحتوى المتقدم

Rich Messages بحسب مخططTDLib المثبت؛ كتل وجداول ووسائط وdraft streaming بحدود واضحة وعزل المؤقت عنالنهائي. ملفات وصلاحيات وتنزيل مدروس. Mini Apps وPayments وLogin URLs تحتاج تنفيذًا متخصصًا واختبارًا أوfallback مفهومًا؛ لا وعد دعم شامل غير مختبر.

## P4 — تثبيت الجودة والإنتاج

توسيع مصفوفة الأجهزة والأحجام وTalkBack والخط واللغات والثيمات. Macrobenchmark/Baseline Profiles وذاكرة وحجمAPK وشبكةضعيفة واستعادةالعملية. اختبار native16KBpages وشروطTelegram والخصوصية والتوقيع الآمن وإصدار قابل للتتبع. القياسات أهداف تحقق وليست نتائج منجزة.

## خارج النطاق

خادم يحتفظ بجلسة المستخدم، استضافة البوتات، جمع توكناتها، AI يخمن أفعالها، مجموعات/قنوات عامة ومتجر أو مدفوعات غير مطلوبة، نسخ أصولTelegram/Apple.

# خارطة BotOS — مراحل مترابطة

## P0 — مكتمل: الذاكرة والعقود

كتبت تعليمات AGENTS والخطط والذاكرة والبنية والتصميم والأمان والقدرات والقرارات ومصادر الإصدارات قبل المصدر. لا تبدأ مهمة جديدة دون قراءة أحدث نسخة وفحص فرع العمل.

## P1 — أساس المعاينة مبني، وجولة الواجهة الثانية قيد التحقق

النسخة 0.1 اجتازت التشغيل 35288442618: اختبارات النواة والتباين والسكربتات وlint والتجميع. جربها المالك على جهازه وأبلغ عن مشكلة الكيبورد وتحديث المفتاح، وطلب إعادة التصميم مع إبقاء الأيقونة.

تستجيب المهمة 0003 لهذه الملاحظات داخل طلب الدمج رقم 2. تشمل توحيد مساحات النظام والكيبورد، وجمع الحالة داخل الوجهات، وتحديث الألوان والتخطيط، ومكتبة محلية وبحث، واختبارات جهاز ولقطات وقياس. لا تعتبر كتابة الاختبارات أو نجاح النسخة السابقة إكمالًا لهذه الجولة. نتائج التشغيل تقرأ وتسجل في TESTING والخطة.

بعد نجاح الجولة تراجع نسخة 0.2 على جهاز المالك ولوحة مفاتيحه. تثبت ملفات Wrapper بعد التحقق منها، وتراجع قواعد النسخ والتحذيرات ذات الصلة قبل الاحتفاظ بجلسة حساب حقيقية.

## P2 — لم يبدأ الاتصال الحقيقي

خطة مستقلة بعد قراءة الذاكرة والقدرات والأمان. تثبيت TDLib على commit ومطابقة JNI والمخطط. بيانات التطبيق خارج Git، ودخول حقيقي بإذن المستخدم، وحماية الجلسة ومحوها عند الخروج، والتحقق من userTypeBot، وإرسال نصوص وأزرار Inline وReply وتحديث الرسائل وإعادة الاتصال. لا توكنات بوتات ولا تعديل webhooks، ولا تكرار `/start` عند كل تنقل.

## P3 — المحتوى المتقدم

تطبيق Rich Messages بحسب المخطط المثبت: كتل وجداول ووسائط ومسودات متدفقة وحدود للحجم والعمق، مع فصل المسودة المؤقتة عن الرسالة النهائية. رفع وتنزيل الملفات بصلاحيات واضحة. Mini Apps والمدفوعات وروابط الدخول تحتاج تنفيذًا متخصصًا واختبارات أو بديلًا صريحًا؛ لا وعد بتوافق شامل غير مختبر.

## P4 — جودة الإنتاج

توسيع مصفوفة الأجهزة والأحجام واللغات والخطوط وTalkBack. قياس الأداء والذاكرة وحجم APK والشبكة الضعيفة واستعادة العملية. Baseline Profiles وMacrobenchmark، ومراجعة 16KB للملفات الأصلية، وشروط Telegram والخصوصية والتوقيع والإصدار القابل للتتبع. نجاح معاينة واحدة لا يغلق هذه البوابة.

## خارج النطاق

خادم يحتفظ بجلسة المستخدم، أو استضافة البوتات، أو جمع توكناتها، أو ذكاء اصطناعي يخمن أفعالها، أو متجر ومدفوعات لم يطلبها المالك، أو نسخ أصول Telegram وApple.

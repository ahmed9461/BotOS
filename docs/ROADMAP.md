# خارطة BotOS — بوابات مترابطة

## P0 — مكتمل: الذاكرة والعقود

AGENTS وخطة وذاكرة وبنية وتصميم وأمان ومصفوفة قدرات وقرارات وإصدارات بمصادر. أُنشئت قبل كود التطبيق.

## P1 — الكود مكتوب، التحقق جارٍ

Compose و5وحدات، ثيمات وRTL وتنقل، تنظيم bookmarks وتفضيلات، نموذج وrenderer ومعاينة مستقلة. نجحت37assertions محلية و14زوج تباين. شرط الإكمال: Android build/lint/tests ناجحة بدليل، مراجعة الوثائق والحدود، وتسليم صريح للمعاينة. خطة tasks/0001-foundation.md. مراجعةUI/جهاز لا تُفترض من نجاح البناء.

## P2 — لم يبدأ الاتصال الحقيقي

TDLib مثبتcommit + JNI + مخطط مطابق، مفاتيح تطبيق خارجGit، login فعلي وحماية الجلسة ومحوها عندالخروج، تحقق userTypeBot، بدء صريح دون تكرار/start كلتبويب، نصوص/Inline/Reply/edits/reconnect مع اختبارات حساب يملكه المستخدم. لا توكنات بوتات ولا تغييرwebhooks.

## P3 — المحتوى المتقدم

Rich Messages بحسبTDLib schema المثبتة، جداول/كتل/وسائط وdraft streaming مع حدود وعزل المؤقت عنالنهائي، ملفات وصلاحيات وتنزيل مدروس. Mini Apps/Payments/Login URLs تنفيذ متخصص واختبار أوfallbackواضح. لا وعد دعم شامل غير مختبر.

## P4 — جودة ونشر

جهاز/أحجام/خط/TalkBack/RTL/English وثيمات، Macrobenchmark/Baseline Profiles وذاكرة وحجمAPK وشبكةضعيفة واستعادةعملية، اختبارnative16KBpages، شروطTelegram وخصوصية وتوقيع آمن وإصدار قابلللتتبع.

## خارج النطاق الحالي

خوادم لحفظجلسات، استضافةالبوتات، جمعتوكناتها، AI يخمنأفعالها، مجموعات/قنواتعامة، متجرومدفوعات غيرمطلوبة أو نسخأصولTelegram/Apple.

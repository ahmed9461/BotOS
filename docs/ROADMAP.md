# خارطة الطريق — بوابات لا يجوز تجاوزها

## P0 — الذاكرة والعقود

خطة وAGENTS وذاكرة وبنية وأمان وتصميم ومصفوفة قدرات. قبول: يمكن لمنفّذ جديد فهم المطلوب والحالة وحدود الإنجاز دون الرجوع للمحادثة. الحالة: قيد التأسيس.

## P1 — شريحة أولى قابلة للتجربة

مشروع Kotlin/Compose، ثيم فاتح/داكن/النظام، واجهات RTL وتبويبات، حفظ الأسماء والتفضيلات، renderer عام ومعاينة محلية واضحة، اختبارات نواة وCI. قبول: build ناجح، اختبار عزل المحادثات وتعديل الرسائل والأفعال القديمة، لا أزرار تدعي خدمة غير منفذة. الحالة: لم يبدأ الكود بعد. خطة: tasks/0001-foundation.md.

## P2 — الاتصال الحقيقي

تثبيت TDLib JNI من مصدر موثق؛ Api credentials خارج Git؛ دخول الهاتف/الكود/2FA وحالات الخطأ حسب المكتبة؛ جلسة مشفرة ومحو عند الخروج؛ بحث البوت والتحقق من userTypeBot؛ بدء صريح؛ نصوص + Inline/Reply keyboard + edits + reconnect. قبول: اختبار حقيقي بحساب تجريبي يملكه المستخدم، ضغط callback صحيح، لا تكرار إرسال أو getUpdates خاص بالبوت. لا ينتقل إصدار live قبلها.

## P3 — المحتوى المتقدم

خريطة Telegram Rich Messages من schema المثبتة، الجداول والكتل والوسائط والـdraft streaming، محددات أحجام وعمق، عزل المسودات المؤقتة عن الرسائل النهائية، download/upload وصلاحيات المستخدم. Payments/Mini Apps/inline queries بحسب دعم مثبت واختبارات؛ fallback آمن للأنواع غير المدعومة. لا وعد بدعم شامل غير مختبر.

## P4 — الإنتاج والجودة

اختبارات RTL/English وثيمات وأحجام شاشة وخط وإمكانية وصول، قياس Macrobenchmark/Baseline Profiles على release، الشبكة الضعيفة وفقد العملية، حجم APK وتسريبات الذاكرة واختبار native 16KB pages، مراجعة شروط Telegram والخصوصية، توقيع محفوظ خارج المستودع وإصدار قابل للتتبع.

## لا يدخل النطاق الآن

سيرفر لتخزين جلسات المستخدم، تشغيل خوادم البوتات، جمع توكناتها، AI يتنبأ بالأزرار، قروبات وقنوات عامة، مدفوعات أو متجر بوتات غير مطلوب، نسخ شعار Telegram أو أصول Apple.

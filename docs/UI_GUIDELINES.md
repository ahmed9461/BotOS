# نظام التصميم — Pearl / Graphite / Mauve

## الهدف

هدوء بصري وشخصية مميزة؛ سطح لؤلؤي في الفاتح وفحم دافئ في الداكن ولمسة موف حجرية. لا كحلي أو أخضر كلون هوية، لا neon أو مؤثرات زجاجية مكلفة على كل بطاقة. الألوان اقتراح تصميمي للمشروع وليست حقائق من مكتبة.

## المكونات

مساحات 4/8/12/16/24/32، أطراف مستديرة 16–28dp، أهداف لمس 48dp أو أكبر. أيقونات vector أصلية بنهايات مستديرة وسماكة موحدة، تُستلهم نعومة iOS دون نسخ SF Symbols أو خطوط Apple. الأيقونة التكيفية للتطبيق يجب أن تحافظ على محتواها داخل المنطقة الآمنة ولا تُرسم كلوغو صغير وسط خلفية شاسعة.

الصفحة الأساسية تعرض الاسم/الإجراء الرئيسي/تبويبات البوتات دون ازدحام. قائمة سفلية قصيرة: المساحة، المظهر/الإعدادات. إضافة البوت شاشة أو sheet واضح، مع اسم محلي قابل للتعديل. للمكتبات الكبيرة استخدم قائمة كاملة وبحثًا بدل حشر عشرات أزرار بالأسفل.

## اللغة

واجهة عربية مفهومة، usernames وروابط وأرقام LTR مع عزل الاتجاه، لا قلب ترتيب نص إنجليزي يدويًا. التبويبات والرجوع من اليمين في العربية. لا نصوص مثل TDLib، callback، renderer، API exception للمستخدم. أمثلة سليمة: «تعذّر الحفظ. حاول مجددًا»، «اتصل بحسابك لاستخدام هذا البوت».

الشريحة المحلية تُظهر «معاينة • لا تتصل بحسابك» بوضوح. الإفصاح عن أن BotOS مستقل ويستخدم Telegram يبقى في المقدمة/عن التطبيق. لا تجمع هاتفًا أو رمزًا قبل وجود اتصال حقيقي.

## الحركة

استجابة الضغط فورية؛ انتقالات قصيرة مستهدفة 180–280ms، spring خفيف بلا ارتداد مبالغ، قابلة للمقاطعة مع النقر التالي. ممنوع delay لتجميل الحركة أو إعادة التحميل عند كل تبويب. خيار تقليل الحركة واحترام مقياس رسوم النظام. سلو موشن بمعنى مرونة الحركة لا إبطاء الاستخدام.

## مراجعة إلزامية

فاتح/داكن، حجم خط 200%، أجهزة صغيرة وكبيرة، TalkBack ووصف الأيقونات، لوحة المفاتيح/insets، ضغط سريع متكرر، اتجاه RTL، تباين، تبويب يحتفظ بمسودته وتمريره. أي ادعاء سرعة يحتاج قياسًا لا انطباعًا.

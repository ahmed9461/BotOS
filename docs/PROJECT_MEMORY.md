# ذاكرة BotOS — نقطة الاستئناف

آخر تحديث: 2026-09-18. المهمة النشطة: [0001-foundation](tasks/0001-foundation.md)، الحالة **validating**.

## المنتج والمتطلبات الثابتة

Android يجمع بوتات Telegram المختارة في تبويبات قابلة للتسمية والترتيب، ويعرض الرسائل والأزرار حسب أنواعها دون تكامل خاص بكل بوت. لا AI يخمن callback. إضافة بوت يستخدم أنواعًا مدعومة لا تتطلب تحديث APK؛ نوع جديد قد يتطلب تحديث المحرك.

العربية/RTL أولًا، English/LTR سليم، Dark/Light/System، هوية Pearl/Graphite/Mauve لا كحلي أو أخضر، أيقونات أصلية ناعمة، حركة قصيرة قابلة للمقاطعة مع تقليل الحركة، لا نصوص هندسية في UI. لا بداية تنفيذ دون قراءة الذاكرة والبنية والخطة والكود.

## ما نُفّذ فعلًا

فحص مستودع ahmed9461/BotOS الفارغ، تهيئة README وملفات P0 على main بالـcommit ca4776f5f9bdf7cdac757daddb036a9722776c22، وإنشاء feat/android-foundation.

كتب أساس التطبيق بخمس وحدات: app، core/model، core/telegram، core/data، core/designsystem. أضيفت واجهات Compose، تنقل Navigation3 محفوظ، ثيمات ومظهر وأيقونة أصلية، DataStore لأسماء وترتيب البوتات والتفضيلات، نموذج رسائل وأفعال مع عزل chat/account/revision، renderer عام، ومعاينة محلية صريحة. لا تسجيل دخول وهمي. يمكن فتح bookmark خارج التطبيق في Telegram.

مصدر أسماء البوتات محلي غير متحقق من هوية Telegram. PreviewGateway مصدر محتوى مصطنع مستقل، ليس تنفيذ TDLib. أنواع SendText/OpenUrl في نموذج الأفعال ليست إرسالًا حيًا. مسودة المعاينة وحالة التمرير مؤقتتان؛ لا ادعاء حفظ رسائل Telegram.

## الأدلة والحالة

النواة جُمعت محليًا باستخدام kotlinc وشغّل JAR: **37 core checks passed**. تباين الألوان من ملفات الثيم: **14 زوجًا اجتاز 4.5:1**. توجد 4 حالات JUnit (واحدة تجمع 37 assertion و3 للمعاينة) بانتظار Gradle CI.

البيئة المحلية بلا Android SDK، وتنزيل الاعتمادات المباشر تعذر. أضيف workflow عبر إجراءات GitHub/Gradle رسمية مثبّتة على SHA، يولد Wrapper ويختبر ويبني APK وتقارير. **لا نتيجة Android CI أو APK مثبتة في هذه اللحظة.** لا جهاز/لقطات/FPS/Baseline Profile أو اتصال حقيقي مختبر.

## قرارات التنفيذ

Kotlin2.4.20 + AGP9.3.1 + Gradle9.6.1 + JDK21؛ لم يُستخدم AGP9.4.0 الأحدث تلقائيًا لأنه خارج حد الدعم الكامل المعلن في مصفوفة Kotlin الحالية. BOM2026.09.00، Nav3 1.1.7، DataStore1.2.1. المصادر والأرقام في DEPENDENCIES.

استُبعد bootstrap تنزيل مخصص لصالح setup-gradle وتوليد Wrapper الرسمي. الملفات المولدة تصدّر من CI، ثم تثبت بعد مراجعتها. لا Room مكرر لرسائل TDLib ولا WorkManager لاتصال حي ولا Hilt دون حاجة.

## الموانع والمخاطر الباقية

توافق المجموعة على Android لم يتحقق حتى نجاح CI. جلسة Telegram تحتاج TDLib commit/JNI/schema متطابقة وapi_id/api_hash خاصين بالتطبيق خارج Git وحماية Keystore وموافقة واختبار حساب. لا ترسل بيانات الدخول في المحادثة أو الوثائق. التفاصيل في SECURITY وTELEGRAM_CAPABILITIES.

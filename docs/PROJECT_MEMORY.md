## C — الكود المكتوب وليس دليل النجاح

MediaReference وفهرس محدود يرتبطان بالحساب والمحادثة والرسالة ومراجعتها. ReceivedMediaController يربط الملفات الحالية بالعرض بتوازي فك2 وثماني معاينات؛ يبطل الصورة والعارض عند حذف أو تعديل الرسالة أو تبديل الحساب. المسار منTDLib وتحت مجلده الخاص فقط. الصور الصغيرة الظاهرة حتى2MiB يمكن تنزيلها تلقائيًا، أما الفيديو والصوت والكبير فبطلب صريح.

MediaDecoder يصغر الصور إلى768px، ويفكTGS بحدود حجم وعمق وتعقيد ومدة، دون صور أو خطوط خارجية أو مراجع دائرية. Media3 يشغل ملفات محلية فقط عبرFileDataSource. عارض واحد خارج القائمة، يبدأ بعد الضغط ويحرر الموارد عند إغلاقه أو الخلفية أو تغير المحادثة. WebP/TGS/WebM لها عرض فعلي؛ الوثائق والخرائط والمضمنات تبقى بديلًا صريحًا. لا WebView أو JavaScript.

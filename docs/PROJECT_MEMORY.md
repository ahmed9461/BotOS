# ذاكرة BotOS — نقطة الاستئناف

آخر تحديث: 2026-09-18. المهمة النشطة: [0005 — ربط الحساب والبوتات](tasks/0005-account-connection.md)، الحالة **planned**. فرع العمل `feat/telegram-connection` يبدأ من `191c04669ab1625e03d52d768b501e38a58c4772` بعد إغلاق P2a. الخطة كتبت قبل كود هذه الشريحة؛ لم يبدأ كود P2b وقت هذا التحديث.

## قبل أي عمل

اقرأ AGENTS ثم هذه الذاكرة والبنية والخارطة والقرارات والأمان والقدرات وخطة المهمة والكود والاختبارات. افحص الفرع وآخر التغييرات، ولا تعتمد على المحادثة بدل الملفات. خطط، نفذ حسب الترتيب، اختبر، وثق؛ لا تتجاوز فشلًا ولا تعتبر وجود ملف اختبار نجاحًا.

## المنتج والهوية المعتمدة

تطبيق Android يجمع بوتات المستخدم في تبويبات يسميها ويرتبها، ويعرض محتواها وأفعالها دون واجهة منفصلة لكل بوت أو AI يتخمن الأزرار. تصميم Porcelain / Graphite / Iris معتمد بالكامل في ADR-007، ومرجعه158c5258. الأيقونة والألوان والتبويبات واللغة العربية RTL والثيمات ثابتة؛ الشاشات الجديدة تستخدم نفس المكونات. لا تغيير بصري جوهري دون موافقة، ولا تغيير لمفاتيح DataStore أو أسماء البوتات وترتيبها.

BotOsApp وحده يملك اتحاد مساحات النظام والكيبورد؛ لا imePadding في composer. تقرأ كل وجهة حالتها داخل NavEntry، ولا تعاد الشاشة قسرًا لإظهار تحديث المفتاح.

## ما نُفذ وثبت

P2a مكتملة كطبقة محرك مستقلة: TDLib/JSONJava مثبت المصدر، وعقد TdRpc/TdTransport، وحالات Authorization، وAndroidTelegramSession بملكية استقبال حصرية، وSessionVault لحماية مفتاح قاعدة الجلسة عبر Keystore/AES-GCM. close يحافظ على الجلسة، وlogOut ينتظر الإقرار والإغلاق قبل محو ملفاتها فقط. التلف أو فقد المفتاح لا يمحو البيانات ضمنيًا.

المصدرe9b45c60 اجتاز35380280277 و35380280304. قُرئت حزمة10562130090 وطابقت بصمتها: **21 JVM و8 JNI/Keystore و3 UI** دون فشل أو تخطي، وlint المحرك0/0. فُتح ملف الجهاز وسبع لقطات وقياس الكيبورد6.095238dp وAAR للمعماريتين. حساب مستخدم لم يُستخدم. [الدليل الكامل](tasks/0004-validation-complete.md) وTESTING هما المرجع؛ لا تكرر إصلاح تعليق الاختبارات القديم.

app ما زال معاينة0.2 محلية في هذه النقطة: لا ربط بالمحرك، لا تسجيل دخول أو إرسال حي. حفظ اسم بوت لا يثبت هويته، وفتح Telegram الخارجي ليس تكاملًا داخليًا. لا تُرسل المعاينة القديمة بوصفها النسخة المتصلة التي ينتظرها المالك.

## الموانع والحدود

بيانات تطبيق Telegram وتوقيع دائم غير مجهزين. الاسمان المخططان لأسرار البناء: BOTOS_TELEGRAM_API_ID وBOTOS_TELEGRAM_API_HASH؛ لا قيم في Git أو المحادثة أو السجلات. لا مفاتيح عينة أو تطبيق آخر، ولا OTP أو كلمة مرور في أي حالة محفوظة. لا تدع أن بيانات العميل داخل APK لا يمكن استخراجها. إصدار غير مهيأ لا يطلب رقمًا أو رمز دخول.

شهادة debug للمعاينة0.2 اختلفت عن0.1؛ لا حذف صامت لبيانات المالك. Wrapper الرسمي فُحص وبصمةJAR موثقة لكنه لم يثبت فيGit بعد. البيئة المحلية بلاAndroidSDK؛ الاختبارات المعلنة عبرActions. ما زالت مراجعةbackup والتوقيع وشروطTelegram والأداء/TalkBack والشبكة الضعيفة والأجهزة المتعددة/runtime16KB مطلوبة؛ محاذاةELF ليست اختبار جهاز16KB. الوسائط وRichMessages الكاملة وstreaming وMiniApps ليست منجزات حالية.

المستخدم طلب الاستمرار وإرسال التطبيق عند جاهزيته. لا تُدّعى جاهزية النسخة المتصلة قبل ربط الوظائف ونجاح الفحوص وتوثيق التهيئة والتوقيع؛ تجربة حسابه تتم داخل التطبيق وبموافقته فقط.

## المنفذ في P2a

native/dependencies.lock.json يثبت TDLib1.8.67 عند d1085f9cebc5a62379991ae1652673954f229c1f، وOpenSSL3.5.7 LTS عند8cf17aaeb4599f8af87fefd810b5b5fee90fe69e، وNDK29.0.14206865. بدأ بناء JSONJava الرسمي على arm64-v8a وx86_64 في35372781224؛ لا نجاح مفترض قبل قراءة نتيجته.

كتبت طبقة TdRpc/TdTransport لربط الطلبات بأجوبتها وترتيب updates وعزل client_id وتحديد السعة والمهلة والإلغاء دون إعادة الفعل. Authorization يقرأ حالات التفويض من المخطط المثبت؛ Ok لا يعني نجاح الدخول. الاستثناءات منقحة دون محتوى الرسائل أو الأسرار.

أضيفت core:tdlib كوحدة Android مستقلة: JsonClient.java الرسمي، ومالك استقبال واحد برمز ملكية يمنع إغلاق كائن قديم من تحرير عميل أحدث، وSessionVault الذي يلف مفتاح قاعدة الجلسة عبر Keystore/AES-GCM داخل noBackupFilesDir. التلف أو فقد المفتاح لا يمسح البيانات ضمنيًا. close محلي يحافظ على الجلسة؛ logOut يتطلب الإقرار والإغلاق قبل المحو. لم يربط app بالوحدة بعد، وهذا ليس تسجيل دخول حقيقيًا أو انتهاء P2b.

كتبت17حالة JVM جديدة وثماني حالات جهاز للمحرك والمخزن؛ نتائجها تنتظر Gradle/CI. محليًا نجحت Python13 وcontrast14 وفحص بنية المستودع وصياغة shell. لا تساو هذه الفحوص بتشغيل JNI أو Keystore على جهاز.

## أول خطوة تالية بالضبط

اقرأ نتيجة بناء native، ثم اجمع مكتبات ABI وschema وJava من نفس التشغيل وتحقق من البصمات. شغل اختبارات JVM الجديدة، وتجميع وlint الوحدة، واختبارات JNI/Keystore الحقيقية مع اختبارات الواجهة الثلاثة السابقة. لا تحذف شرطًا فاشلًا. حدث TESTING والخطط وهذه الذاكرة والسجل بالنتائج المقروءة وروابطها، قبل إعلان اكتمال الشريحة.

## ما لم يكتمل

P2b لربط شاشة الحساب ومساحات البوتات بالمحرك، وبيانات تطبيق Telegram خارج Git، واختبار حساب بموافقة المالك. لا OTP أو كلمة مرور في المحادثة. إدارة إرسال الرسائل وأزرار البوتات وedits/reconnect، والمحتوى المتقدم والوسائط وstreaming، وتوقيع إصدار دائم، وbackup وسياسات النشر، وقياس الأداء و16KB runtime مراحل مستقلة. ملفات ELF بمحاذاة16KB ليست بديلًا لاختبار الجهاز16KB.

البيئة المحلية بلا Android SDK والوصول المباشر لتنزيل Git/Maven تعذر؛ المصدر استعيد من artifact CI، والتحقق عبر GitHub Actions. جميع نقاط التوقف والحدود موثقة، ولا ادعاء عمل غير منفذ أو استمرار تلقائي بعد انتهاء المحادثة.

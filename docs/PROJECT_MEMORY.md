# ذاكرة BotOS

آخر تحديث: 2026-09-18. هذا الملف هو نقطة الاستئناف، وليس سجل محادثة أو مخزن بيانات مستخدم.

## ما المشروع؟

تطبيق Android يجمع بوتات Telegram التي يختارها المستخدم في تبويبات قابلة للتسمية والترتيب. الرسائل والأزرار تأتي من البوت وتُعرض بمحرك عام حسب نوع المحتوى. لا تكامل مخصص لكل بوت، ولا AI لتخمين التنقل. إضافة بوت يستخدم أنواعًا مدعومة لا تتطلب تحديث APK؛ الأنواع الجديدة قد تتطلب تحديث المحرك.

## متطلبات المالك الثابتة

العربية وRTL أولًا، English وLTR سليمين داخل النص المختلط. واجهة هادئة فاخرة، Dark/Light/System، ألوان لؤلؤية وفحمية ولمسات موف/وردي حجري لا كحلي أو أخضر كهوية. أيقونات أصلية ناعمة، لا نسخ أصول Apple. تنقل سهل مع حفظ حالة كل تبويب. الحركة مرنة وقابلة للمقاطعة وليست تأخيرًا مفتعلًا. لا نصوص هندسية في واجهة الاستخدام.

## الحالة الفعلية الآن

- تم فحص `ahmed9461/BotOS` عبر GitHub؛ كان فارغًا، والفرع الافتراضي `main`.
- تم تهيئته بـ README، ثم إعداد ملفات الحوكمة والتخطيط قبل كتابة التطبيق.
- المهمة النشطة: `docs/tasks/0001-foundation.md`.
- لا APK ولا تسجيل دخول أو اتصال Telegram مثبتين حتى الآن.
- البيئة المحلية تملك Java وKotlin، ولا تملك Android SDK. الوصول الشبكي المباشر لتنزيل Maven/Gradle فشل. اختبار Android مخطط عبر GitHub Actions؛ يسجل النجاح فقط بعد مشاهدة النتيجة.

## القرارات المرجعية

Kotlin + Compose + TDLib مستهدف. UDF ومستودعات بيانات وحدود واضحة. لا اعتماد على Bot API للتصرف كمستخدم. التخزين المحلي الصغير DataStore؛ تخزين الرسائل والجلسة من اختصاص TDLib عند ربطه؛ لا نسخ قاعدة رسائله كاملة إلى Room. Room وWorkManager وHilt إضافات عند حاجة فعلية وليس طقوس تأسيس.

## حدود الشريحة الأولى

إنشاء مشروع Android قابل للبناء، نظام ألوان وأيقونة، واجهات البداية/المساحة/المظهر، تنظيم أسماء البوتات محليًا، محرك محتوى وأزرار عام، ومعاينة محلية صريحة لا تتصل بالحساب. اختبارات نواة وتوثيق وبناء CI. مرحلة الاتصال الحقيقي منفصلة ببوابة اعتماد الجلسة وTDLib.

## موانع قبل الاتصال الحقيقي

تثبيت TDLib على commit محدد وبناء JNI والتحقق من schema ومطابقته، إعداد `api_id` و`api_hash` الخاصين بالتطبيق خارج Git، وتطبيق حماية الجلسة والخصوصية وتدفق الدخول الحقيقي. لا تجمع أكواد دخول على شاشة شكلية.

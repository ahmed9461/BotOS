## المنتج والحدود الثابتة

تطبيق Android يجمع بوتات Telegram المختارة في تبويبات قابلة للتسمية والترتيب. المحتوى والأزرار يعرضها محرك عام حسب النوع؛ لا ذكاء اصطناعي لتخمين الأفعال ولا تكامل خاص لكل بوت. إضافة بوت يستخدم أنواعًا مدعومة لا تتطلب تحديث التطبيق؛ دعم نوع جديد قد يتطلب تحديث المحرك.

العربية واتجاهها من اليمين أولًا، مع سلامة الإنجليزية داخل النص المختلط، وثيمات الفاتح والداكن والنظام. لا مصطلحات هندسية في واجهة المستخدم. **النسخة الحالية معاينة محلية فقط:** لا تسجيل دخول أو TDLib أو إرسال حقيقي. أسماء البوتات محفوظات محلية لم يُتحقق من هويتها في Telegram. فتح الرابط خارجيًا ليس اتصالًا حيًا داخل BotOS.

## ملاحظات المالك الملزمة في الجولة الثانية

جرّب المالك النسخة 0.1 وأرسل صورتين. لاحظ فراغًا كبيرًا بين لوحة المفاتيح وحقل الكتابة، وعدم تحديث زر تقليل الحركة حتى مغادرة المظهر والعودة إليه. رأى الألوان ثقيلة وغير متناسقة وطلب تحسين الواجهات بصورة حقيقية. أعجبته فكرة المكتبة والتبويبات.

**أيقونة التطبيق أعجبته جدًا. يحظر تغيير ملفاتها أو خلفيتها دون طلب جديد.** يوجد فحص يقارن ملفات الأيقونة مباشرة بالنسخة المعتمدة. مفاتيح DataStore وأسماء البوتات وترتيبها لا تُغير ولا تُمسح.

## التنفيذ المكتوب في المهمة 0003

أصبح `BotOsApp` المالك الوحيد لمساحات النظام وحواف الشاشة ولوحة المفاتيح، ويأخذ اتحادها بدل جمعها. لا يضيف حقل الكتابة أو المحرر مساحة لوحة مفاتيح أخرى. يختفي شريط التنقل والرأس الموسع أثناء الكتابة، ولا تُحجز مساحة لشريط مخفي.

تجمع وجهات التطبيق حالتها داخل محتواها، خصوصًا `AppearanceRoute`، بدل تمرير لقطة إعدادات محسوبة خارج `NavEntry`. حالة المفتاح والنص المصاحب والثيم مرتبطة بمصدر الحالة نفسه؛ لا تغيير قسري لمفتاح الشاشة لإجبار إعادة إنشائها.

أعيد تصميم الألوان إلى Porcelain / Graphite / Iris، مع تقليل الأسطح البنية والأحجام المبالغ فيها. أضيفت بلاطات معاينة للثيم، وحقل إدخال موحد، ومحرر أبسط، وبطاقات محتوى محسنة، ومكتبة محلية قابلة للبحث. الإصدار المستهدف `0.2.0-preview`، ورقم الإصدار 2.

أضيفت ثلاثة اختبارات تشغيل على محاكي Android بمستوى API 35: التبديل المتكرر والثيم والحفظ، ظهور لوحة مفاتيح حقيقية وقياس الفراغ، وحفظ مدخلات المحرر عبر إعادة إنشاء النشاط. تحفظ لقطات فعلية وتقارير. فحوص ثبات الأيقونة وتطابق الترجمة وملكية المساحات تكمل اختبار الجهاز ولا تستبدله.

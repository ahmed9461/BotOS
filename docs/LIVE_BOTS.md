# محادثات البوتات الأساسية

2026-09-18. الكود مكتوب والاختبارات الجديدة تنتظر التشغيل؛ لم يستخدم حساب المالك أو تُجر مصادقة منCI.

## تدفق البيانات

AccountCoordinator.ready → BotConversations → BotMessageReducer/Adapter → ConversationState → LiveBotViewModel/Panel → محرك العرض الحالي. JSON يبقى داخل core:telegram، ولا يصل إلى الواجهة. منسق واحد للمحادثة النشطة، ومحدد تسلسل خارج خيط الرسم، وصف تحديثات بسعة256. عند تجاوز السعة يتوقف إرسال الأفعال وتظهر ضرورة التحديث؛ لا إسقاط صامت.

يتحقق searchPublicChat من محادثة خاصة، ثم getUser منuserTypeBot. لا يستنتج ذلك من الاسم. openChat والتاريخ لا يرسلان/start؛ زر بدء البوت هو الفعل الصريح. يفصل ChatKey بين هوية الحساب وجيله والمحادثة وجيل التبويب. النتائج والأزرار القديمة لا تنفذ على السياق الجديد.

## الرسائل والأفعال

تاريخ أولي حتى50رسالة وحد عرض200رسالة. يحفظ أحدث المحتوى والأزرار، ويطبق التحديثات المصفوفة بعد تحميل التاريخ حتى لا يضيع تعديل مبكر. تحديث الإرسال النهائي يمنع رجوع المعرف المؤقت من جواب متأخر. حالةpending ليستsent؛ الفشل يظهر دون إعادة إرسال تلقائية. مسودة النص مؤقتة وتزال عند تغيير سياق الحساب/المحادثة.

Inline callbacks تحتفظ ببياناتbase64 كما وردت؛ Reply النصي يرسل نصه الأصلي، ولوحته النشطة منفصلة عن التاريخ، وone_time يمر بـdeleteChatReplyMarkup. updateChatReplyMarkup يقرأreply_markup_message لا مخططًا قديمًا. الأزرار الخاصة غير المدعومة معطلة. الروابطHTTP/HTTPS فقط، دونuserinfo أومحارف تحكم، وتحتاج تأكيدًا.

## الواجهة والحدود

المكتبة والمعاينة والمظهر والأيقونة كما اعتمدها المالك. تعرض المساحة محادثة البوت بدل بطاقة الرابط فقط. أثناء الكيبورد يختصر الرأس ويظل BotOsApp وحده مالكInsets. المتابعة من الحساب ثم البوت داخل التطبيق، وليس فتحTelegramالخارجي بديلًا مخفيًا.

هذا نطاق نصوص وأزرار أساسية: لا وسائط محملة أو ملفات مرفوعة أو Rich Messages/streaming أو MiniApps/Payments أو طلب هاتف/موقع مزعوم. نصوصmedia captions قد تعرض مع بديل يبين أن المحتوى غير مدعوم. لا ادعاء توافق كل بوت أو اختبار شبكة ضعيفة أو TalkBack/FPS شامل.

# ملحق تنفيذ المهمة 0004 — النقل ومخزن الجلسة

التاريخ: 2026-09-18. الخطة الأصلية 09aaffca كتبت قبل التنفيذ. هذا الملحق يسجل الشريحة ضمنها، وحالتها validating وليس نجاحًا مفترضًا.

## المنفذ وحدوده

أضيف TdTransport بعقد TdRpc وربط الطلبات بأجوبتها عبر @extra، وحد انتظار، وإلغاء دون إعادة إرسال، وتسلسل updates وعزل client_id. أضيف Authorization لحالات Telegram الموثقة من المخطط المثبت؛ Ok لا يعني نجاح الدخول. لا تخزين دائم للرمز أو كلمة المرور، والاستثناءات لا تحمل النص الخام.

وحدة core:tdlib مستقلة عن واجهات المعاينة. تحتوي JsonClient.java الرسمي كما ورد في commit TDLib المثبت، ومالك استقبال واحد على مستوى العملية، وSessionVault بمفتاح عشوائي32بايت ملفوف بواسطة Android Keystore/AES-GCM داخل noBackupFilesDir. تلف المفتاح أو فقده مع قاعدة موجودة يفشل صراحة بدل استبدال البيانات. close لا يمحو الجلسة ولا يزعم إلغاءها. logOut ينتظر الإقرار والإغلاق قبل المحو، ويحجز ملكية الجلسة حتى انتهاء المحو. إغلاق كائن قديم لا يحرر ملكية عميل أحدث.

لم يربط app بهذه الوحدة بعد؛ لا شاشة دخول شكلية ولا حساب مستخدم استُخدم. مكتبة مبنية أو اختبار رمز مصطنع ليس تسجيل دخول حقيقيًا.

## الاختبارات

كتبت17حالة JVM جديدة: correlation، عكس ترتيب الأجوبة، client_id آخر، timeout، الإلغاء، عدم تكرار الفعل، ترتيب updates، إلغاء الاشتراك، غلق pending، السعة، JSON معطوب، تزوير extra، حالات التفويض، البيانات الثنائية، الطلبات المتزامنة، logout الفاشل وحالات غير شائعة. تضاف إلى4حالات الأساس.

كتبت8حالات Android: تحميل JNI والإصدار والعربية/emoji والإغلاق والملكية؛ إنشاء/استعادة مفتاح Keystore وعدم كتابته مكشوفًا، والتلف وفقد المفتاح وطول غير صالح وعزل المحو. تنتظر تشغيلًا فعليًا بعد بناء native؛ لا تعتبر ناجحة من وجود ملفاتها.

محليًا شُغل check_repo وcheck_contrast وbash -n وPython unittest: الفحوص اجتازت، Python13 وcontrast14. لا Android SDK محليًا، ولذلك Gradle/JNI/Keystore بانتظار CI.

## التحقق التالي

نجاح مصفوفة native ثم جمع مخرجات نفس التشغيل والتحقق من SHA/schema/Java؛ تجميع الوحدة والاختبار وتشغيل اختبارات الجهاز الجديدة مع اختبارات الواجهة السابقة دون حذف أي شرط. اقرأ تقارير XML وnative-runtime.txt وأدلة UI، وسجل النتيجة في الذاكرة والسجل. البنية المفصلة في TELEGRAM_RUNTIME، والبوابات الأصلية في0004-telegram-runtime.

## المنفذ

أضيفت قيم BuildConfig من زوج بيئة البناء أو زوج local.properties المستبعد من Git، دون خلط المصدرين. ID موجب ضمن int32 وhash بصيغة hex32؛ الغياب الكامل يعطل التهيئة، والجزئي أو المشوه يوقف البناء برسالة عامة. TelegramBuildConfiguration.credentialsOrNull يجهز عقد الاعتماد فقط ولا يفتح حسابًا.

Workflow Telegram build configuration خاص بالمالك والفرع الحالي وحدث push أو dispatch، دون أسرار في PR CI. يستقبل القيم عبر env لخطوة واحدة؛ يتحقق من الصيغة وتطابق BuildConfig المولد داخل runner، دون رفع ناتجه أو طباعة قيمة/طول/بصمة سر. cache معطلة، ولا build scan أو APK من هذه المهمة. التهيئة ليست موافقة المستخدم ولا اختبار قبول المفاتيح من خوادم Telegram.

في المحاكي فقط: منع نوم الشاشة أثناء الاختبارات وإيقاظها وإغلاق قفل غير آمن، مع رفض الجهاز غير المحاكي أو المحمي. أضيف التقاط صورة وحالة النافذة والطاقة عند الفشل. بقي شرط التركيز ومهلته ومعيار فجوة الكيبورد واختبارات الحفظ كما هي. لم تتغير الألوان أو الأيقونة أو واجهة الإنتاج أو مفاتيح DataStore.

## المخاطر والتخفيف

اختلاف أحدث إصدارات المكتبات: اختبار مجموعة كاملة قبل التسليم. عدم توفر Android SDK محليًا: CI ودليل run؛ لا تزوير نجاح. rich schema مختلف عن Bot API: في P1 نموذج داخلي لا ادعاء توافق كامل. تغير callbacks: هوية chat/message/revision واختبارات stale actions. بطء واجهة: lazy lists وحفظ الحالة وحركة قصيرة؛ القياس على جهاز مؤجل ومعلن.

## الاختبارات المخططة

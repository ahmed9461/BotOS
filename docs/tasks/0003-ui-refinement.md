# المهمة 0003 — إصلاح الإدخال وتحديث المظهر

التاريخ: 2026-09-18. الحالة: in_progress. الفرع: feat/ui-refinement-v2. البداية: 914ab1363c8befa606a47defb53268d372b809d1 من feat/android-foundation / PR1. المالك جرّب APK0.1 وأرسل صورتين ثم وافق على التنفيذ.

## المطلوب

إزالة الفراغ بين لوحة المفاتيح وحقل الكتابة، تحديث تقليل الحركة في الشاشة نفسها، إعادة ترتيب الواجهات واستبدال الجو البني/الموف الثقيل بلوحة أخف ومتناسقة. الحفاظ على أيقونة التطبيق حرفيًا وعلى الأسماء المحفوظة وفكرة التبويبات. المعاينة تبقى غير متصلة بـTelegram.

## القراءة والتشخيص قبل الكود

قرئت AGENTS والذاكرة والبنية والخارطة والقرارات والسجل والتصميم. فُحص PR1 وcommit914ab136 وشجرة الملفات. لا عمل جديد على main ولا إعادة تأسيس. فُحص BotOsApp وSettingsScreens وMessageRenderer وWorkspaceStore ونظام الألوان. المسار الحالي يوزع inset handling بين Scaffold وحقل الكتابة ولا يستهلك padding الأب؛ كما تمرر preferences محسوبة خارج NavEntry إلى محتواه. هذه مسارات مشتبه بها تدعمها شكاوى الجهاز، ويجب إثبات الإصلاح باختبار تشغيل، لا بالصور وحدها.

## معايير القبول

إظهار تغير switch داخل وجهة المظهر دون مغادرتها، والتحقق من persisted value بعد activity recreation. حقل الإدخال أعلى IME بفاصل بصري صغير (هدف <=12dp عند الاستقرار)، لا مساحة لشريط تنقل مخفي. المصطلحات الهندسية خارج الواجهة. صور حقيقية للفاتح/الداكن وليست رسومات مفترضة. الاختبارات غير المشغلة تبقى معلنة. نجاح lint ليس إثبات FPS.

## المخاطر والتراجع

NavEntry قد يحتفظ بالمحتوى؛ الإصلاح قراءة State داخل الوجهة دون تغيير key قسرًا أو فقد حالة. Insets تختلف حسب النظام ولوحة المفاتيح؛ اختبار المحاكي ثم إعادة اختبار جهاز المالك. احتفظ بأدلة الفشل، ولا disable lint. إن تعذر المحاكي سجّل السبب ولا تسمِّ screenshot من preview دليل تشغيل. التراجع عبر revert شريحة0003 دون مساس بالأساس. توقيع debug مؤقت وقد لا يطابق النسخة السابقة؛ لا ادعاء تحديث فوقها دون فحص الشهادة.

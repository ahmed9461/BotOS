## المطلوب

## القراءة والتشخيص قبل التنفيذ

قرئت تعليمات AGENTS والذاكرة والبنية والخارطة والقرارات والسجل والتصميم، وفحصت الشجرة وطلب الدمج والمصادر المتعلقة بالشاشة والتخزين. كان التعامل مع المساحات موزعًا بين Scaffold وحقل الإدخال، وكانت قيمة preferences محسوبة خارج محتوى NavEntry. تغير التنفيذ لمعالجة هذين المسارين، مع اختبار جهاز مطلوب لإثبات النتيجة.
